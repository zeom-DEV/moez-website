Confidentialité & informations du site

Mise à jour : 19 octobre 2026.

Contact professionnel

Moez, professionnel indépendant basé en Tunisie. Pour toute question sur le site ou une prestation : contact@moezthabet.com. Le périmètre et les informations nécessaires à la contractualisation sont précisés avant une mission.

Votre message de contact

Le site prépare le message dans votre navigateur. Les champs du brief ne sont pas enregistrés par le site. Le bouton de contact ouvre votre messagerie ; le message est transmis lorsque vous choisissez de l’envoyer. Le bouton de copie place le texte dans votre presse-papiers.

Prise de rendez-vous

Le lien de réservation ouvre Calendly dans un autre onglet. Les informations saisies sur Calendly relèvent de son fonctionnement et de ses règles de confidentialité.

Hébergement et ressources

Le site public est hébergé sur GitHub Pages. Les images, scripts et styles du site sont servis avec les pages ; aucune police distante ni intégration de calendrier n’est chargée à l’ouverture. L’hébergeur et les services externes consultés peuvent traiter les données techniques nécessaires à leur fonctionnement.

Cookies et mesure d’audience

Cette version n’intègre pas de traceur publicitaire ou d’outil de mesure d’audience tiers. Les liens vers LinkedIn, GitHub et Calendly conduisent à des services ayant leurs propres règles.

Contenus présentés

Les entreprises mentionnées dans le parcours correspondent aux expériences professionnelles indiquées. Le site est présenté comme un projet personnel. Les visuels de prestations et scénarios pédagogiques ne représentent pas des dossiers clients réels.

Demandes concernant le site

Vous pouvez écrire à contact@moezthabet.com pour une demande relative au contenu ou aux informations que vous avez transmises.
